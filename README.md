# 💼 Job Application Tracker

A Python-based job application management system that helps users organize and track their job applications, interviews, and application statistics in one place.

## 📌 About the Project

**Job Application Tracker** is a console-based application built with Python and SQLite.

The application allows multiple users to create accounts and manage their own job applications. Users can add new applications, update their status, search and filter applications, manage interviews, view statistics, and export their application data to CSV.

This project was created to practice **Python, SQL, database design, authentication, CRUD operations, data validation, and file handling** through a real-world use case.
